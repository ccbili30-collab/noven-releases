# Noven

诺文是一个本地优先的创作工作台：项目、世界卡、角色卡、文稿、画布和 AI 对话都在你自己的 Mac 上。没有云端账户，没有自动上传；只有你主动使用模型时才会发起网络请求。

## 系统要求

- Apple Silicon（arm64）Mac
- macOS 13 或更新版本
- 首发不提供 Intel 版本

## 安装

1. 下载 `Noven-20261023-03c11ee084-arm64.dmg`。
2. 打开 DMG，把 **Noven.app** 拖到「应用程序」。
3. 第一次打开会被 macOS 拦截，因为当前构建没有 Apple 开发者签名：
   - 右键点击 Noven.app → **打开** → 再点 **打开**；或
   - 打开「系统设置 → 隐私与安全性」，在底部点 **仍要打开**。
4. 打开后直接进入工作台；模型在「设置 → 模型」里配置。

## 更新

当前不做自动更新。下载新的 DMG，覆盖安装即可；应用数据保存在：

```text
~/Library/Application Support/Noven/
```

项目文件夹由你自己选择，应用不会移动或覆盖它们。
